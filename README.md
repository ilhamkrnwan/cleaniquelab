# Cleanique Lab (cleaniquelab.com)

Official website and WordPress theme for **Cleanique Lab** — Indonesian producer and manufacturer of cleaning chemicals, bulk liquid soaps, concentrate soap packs, and institutional hygiene solutions.

---

## 🚀 Overview & Features

- **Custom WordPress Theme**: `cleaniquelab-theme` built from the ground up with responsive layouts, modern CSS variables, Lucide vector icons, and smooth micro-interactions.
- **Rich Commercial Catalog**: Household soaps, commercial laundry detergents, antibacterial hand soaps, hospital-grade floor carbol, and concentrate soap paste packs.
- **Enterprise SEO & Local GEO Schema**:
  - `Organization`, `LocalBusiness`, and `Manufacturer` JSON-LD schemas.
  - Coverage hubs for 38 Indonesian provinces.
  - `FAQPage` structured data.
- **Interactive Features**:
  - Category filter tabs on Pricelist page.
  - WhatsApp dynamic message generator form for B2B wholesale orders.
  - Edge-docked Privacy & Cookie slide-out widget.
  - Floating WhatsApp hotline button.
  - Multi-brand ecosystem network backlinks.
- **Social & Marketplace Channels**: Official links for Instagram (`@cleaniquelab`), Shopee Official Store, and TikTok Shop.

---

## 🎨 Design System

- **Primary Colors**: Cyan (`#00d2ff`) to Royal Blue (`#3a7bd5`) Brand Gradient.
- **Vibrant Accents**: High-Impact Lime Green (`#aef711`, `#7edb0d`) & Conversion Coral/Orange (`#ea501f`).
- **Footer**: Dark Slate (`#2b2b33`).
- **Typography**: `Source Sans 3` / `Open Sans` (Headings) and `Open Sans` (Body).

---

## 🛠️ Tech Stack & Requirements

- **CMS**: WordPress 6.x / 7.x
- **PHP**: 7.4+
- **Database**: MySQL 5.7+ / MariaDB 10.3+
- **Theme**: `wp-content/themes/cleaniquelab-theme`
