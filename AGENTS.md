# Cleanique Lab Workspace Rules & Frontend Standards

## Overview
This repository is the web application and website for **Cleanique Lab** (`cleaniquelab.com`), manufacturer and producer of cleaning chemicals, soaps, and hygiene solutions.

Whenever designing, updating, or generating any frontend code, components, styles, or UI pages for this project, you **MUST** adhere to the following rules:

---

## 1. Design System Enforcement
- Follow the official guidelines documented in [cleaniquelab-design-system.md](file:///c:/laragon/www/cleaniquelab/.agents/rules/cleaniquelab-design-system.md).
- Use the **Cleanique Lab Color Palette**:
  - Primary Brand Gradient: Cyan to Royal Blue (`radial-gradient(circle farthest-side, #00d2ff 35px, #3a7bd5)` or `linear-gradient(135deg, #00d2ff, #3a7bd5)`).
  - High-Impact Lime Green Accents: `#aef711`, `#b4fc6c`, `#7edb0d`.
  - High-Conversion CTA Coral/Orange: `#ea501f` / `#ff6900`.
  - Dark Slate Footer & Contrast: `#2b2b33`, `#23232d`.
  - Product Category Gradients: Green (`#109733` $\to$ `#7edb0d`), Purple (`#6d0a6c` $\to$ `#a51da3`), Blue (`#3a7bd5` $\to$ `#00d2ff`), Red (`#c61111` $\to$ `#f71b1b`).

## 2. Typography Standard
- **Headings**: `'Source Sans 3'`, `'Open Sans'` (Heavy weights: 700, 800, 900).
- **Body**: `'Open Sans'` (400, 500, line-height: 1.5 - 1.6).
- **Badges & Labels**: `'Ubuntu'`, `'Inter'` (Bold uppercase with letter spacing).

## 3. UI Patterns & Aesthetics
- **Organic Wave Transitions**: Use smooth SVG wave / curved dividers between sections.
- **Pill Buttons & Tactile Cards**: Use rounded pill buttons (`border-radius: 50px` or `1000px`), smooth hover scales (`transform: scale(1.05)`), and elevated drop shadows.
- **Avoid Generic AI Defaults**: Do NOT produce generic, monochrome, or unstyled layouts. Every view should feel polished, vibrant, and aligned with Cleanique Lab's commercial hygiene branding.
- **Distinctive Intentionality**: Use the installed `frontend-design` and `cleaniquelab-design-system` skills whenever creating or reshaping UI components.
